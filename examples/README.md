# Examples

Five recipe + schema docs covering the four user-facing surfaces (stations, ⌘K DJ, settings, scenes) plus the data layer (taste profile).

| File | What it covers |
|---|---|
| [`stations.md`](./stations.md) | `data.js` schema + 10 sample station configs (Late Night Drive, Morning Coding, 90s Grunge, Rainy Afternoon, etc.) |
| [`dj-commands.md`](./dj-commands.md) | Cmd+K cookbook — example prompts for create / refresh / add / remove, broken down by intent |
| [`settings.md`](./settings.md) | Each toggle explained (bridge tracks, BPM lock, album-art tint) + recommended presets + how to hand-edit `localStorage` |
| [`scenes.md`](./scenes.md) | How to add a new scene/room — full walkthrough adding a "forest" scene from scratch |
| [`taste-profile.md`](./taste-profile.md) | What gets tracked (listen-throughs, skips, known artists), where it's stored, how the DJ + replenishment use it, how to inspect/reset |

Start with `stations.md` if you're setting up your dial, `dj-commands.md` if you want to know what the DJ can do, `scenes.md` if you're customizing visuals.
